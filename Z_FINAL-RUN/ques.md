# Problem Solving Practice - Question List

## Arrays & Strings (Foundations)

1. [DONE] Given an array of integers, find two numbers that add up to a target value — solve it in one pass (Two Sum). 
2. [DONE] Find the longest substring without repeating characters in a string.
3. [DONE] Given a string, determine if it's a valid palindrome, ignoring non-alphanumeric characters and case.
4. Merge two sorted arrays into one sorted array in-place.
5. Given an array, find the maximum sum of any contiguous subarray (Kadane's Algorithm).
6. Write your own sorting function (implement Bubble Sort or Insertion Sort from scratch, not using a built-in sort).
7. Given an array of integers, find the largest and smallest number without using any built-in min/max functions.
8. Reverse an array in-place (without creating a new array).
9. Given an array, remove all duplicate values and return only unique elements.
10. Check if an array is a palindrome (reads the same forwards and backwards).
11. Given two arrays, find the union and intersection of their elements.
12. Rotate an array to the right by `k` steps (e.g. `[1,2,3,4,5]` rotated by 2 → `[4,5,1,2,3]`).
13. [DONE] Given a string, count the frequency of each character in it (e.g. `"aabbbc"` → a:2, b:3, c:1).
14. [DONE] Check if two strings are anagrams of each other (contain the same characters, just rearranged).
15. Given an array of integers, move all zeros to the end while keeping the relative order of non-zero elements (e.g. `[0,1,0,3,12]` → `[1,3,12,0,0]`).
16. [DONE] Majority Frequency Characters

## Hashing & Sliding Window

17. Group anagrams together from a list of strings.
18. Find the smallest window in a string that contains all characters of another string.
19. Given an array of stock prices by day, find the maximum profit from one buy and one sell.

## Recursion & Backtracking

20. Generate all valid combinations of n pairs of parentheses.
21. Given a set of distinct integers, return all possible subsets (the power set).
22. Solve a simplified N-Queens problem (place N non-attacking queens on an N×N board).

## Trees & Graphs

23. Given a binary tree, return its level-order traversal (BFS).
24. Detect a cycle in a directed graph.
25. Find the shortest path between two nodes in an unweighted graph using BFS.
26. Given a nested object/JSON structure, write a function to flatten it into dot-notation keys.

## Dynamic Programming

27. Solve the classic "climbing stairs" problem (count distinct ways to reach the top, taking 1 or 2 steps).
28. Given a set of coin denominations, find the minimum number of coins to make a target amount.
29. Find the longest common subsequence between two strings.

## System / Practical Thinking

30. Design and implement a simple in-memory LRU cache with `get` and `put` operations in O(1) time.
31. Implement a debounce and a throttle function from scratch in JavaScript/TypeScript.
